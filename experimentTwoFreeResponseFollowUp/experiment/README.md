### Experiment Two (Free-Response) of the Overinformativeness Project: Code for Behavioural Data Collection

HTML files can be located under templates. CSS and Javascript files can be found under static/css and static/js, respectively. Stimuli can be found in static/stimuli, along with python scripts code that produces the stimuli, where relevant.

Running the experiment locally requires downloading psiTurk (https://psiturk.org/) and its requirements.
