### Experiment One of the Overinformativeness Project: Code for Behavioural Data Collection

HTML files can be located under templates. CSS and Javascript files can be found under static/css and static/js, respectively. Stimuli can be found in static/stimuli, along with python scripts code that produces the stimuli, where relevant. In stimuli, 'audio' contains the original synthesised sounds from Traer et al. and all possible combinations of sounds between the materials in their original paper, and the jupyter notebook that generates the synthesised sounds and the continuums. 'colour' has the orange--yellow blue--green hundred-step continuums (every second step was used in the experiment), and 'pyColourRun' has a python script to generate the colours.

Running the experiment locally requires downloading psiTurk (<https://psiturk.org/>) and its requirements.
