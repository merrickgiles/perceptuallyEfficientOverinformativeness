### Experiment One of the Overinformativeness Project: Code for Behavioural Data Collection

HTML files can be located under templates. CSS and Javascript files can be found under static/css and static/js, respectively. Stimuli can be found in static/stimuli, along with python scripts code that produces the stimuli, where relevant. In stimuli, 'audio' contains the auditory material stimuli, with the continuum material and position listed. 'colour' has the orange--yellow blue--green hundred-step continuums (every second step was used in the experiment), and 'pyColourRun' has a python script to generate the colours.

To run the experiment locally, you will have to first download psiturk: https://psiturk.org

If you successfully set up the experiment, you will be required to input a password on the first page (the audio file revealing the password has been removed). The password is 'koala'.
